# Sen Live2D Companion Android

Sen 专用的 Android Live2D AI 伴侣实验项目。它与“迷梦”项目完全分离，避免不同模型的参数、外观预设和调试结论互相污染。

## 当前版本：v0.4.9 Sen呆毛固定锚点与模型局部微调版

项目使用 Live2D 官方 Cubism SDK for Java 5 R5 与 Android 原生 OpenGL。C高精度蒙版已解决Sen的60组蒙版溢出造成的白块、缺刘海、嘴、手指和耳朵错层；当前继续验证内置换装和动态表现。

- 导入用户本机的 Sen 模型 ZIP，不将模型写入仓库或 APK。
- 自动扫描 ZIP 中未登记的 `.exp3.json` 并补写到 App 私有目录内的 `model3.json` 副本。
- 首次另行导入电脑采集器输出的 `Sen.vts-profile.json` 作为动态外观底座；文件只保存到 App 私有目录，不进入仓库或 APK。
- 内置女仆装、白衬衫和兔女郎三套服装按钮。服装只覆盖16项稳定部件参数和对应ArtMesh颜色，不写入九轴、眼睛、手臂、呼吸或物理瞬时值。
- 女仆装与白衬衫共用配色，兔女郎使用独立配色；`ArtMesh210/276/1324/1689`按确认补为`#444573`，白衬衫会关闭`Maid Headband`。
- VTS底座每帧恢复后依次叠加服装、20个情绪入口、26个动作、原生物理、隔离兔耳物理、尾巴镜像与呆毛运行时几何，动作不会累积破坏换装。
- 预览区可开启调整模式：单指拖动、双指缩放，并可还原位置与大小。
- C高精度蒙版已解决Sen的60组蒙版溢出导致的白块、缺刘海、嘴、手指和耳朵错层；默认使用1024蒙版，并保留512/1024两档用于性能与耳缘对照。
- 兔耳“快速摆动两次”继续复用慢眨眼的九轴→原生物理路线：正常物理与隐藏耳朵物理分别计算，只取隐藏物理的`ParamL_angle / ParamR_angle / ParamR_angle2`三项输出。用户确认预设为速度135%、幅度100%，界面仍保留50%～250%独立试调；自主待机会约每28～68秒低频触发一次。
- 26个程序动作采用迷梦实机确认的关键帧、错相风摆、展示环绕和摸头路线；中间关键点使用连续速度三次曲线，动作切换交叉淡化，动作期左右手臂物理压到35%，结束后用0.55秒平滑释放到100%。
- 情绪参数以0.42秒交叉淡化；ZIP预设动作/表情本轮不改。程序动作在启动时校验曲线完整性，普通曲线必须从0进入并回到0。
- 预览区默认开启迷梦同路线的极限触屏跟随；摸头范围保存为模型局部归一化`L/T/R/B`，每次触摸都会按模型当前平移、缩放和画面宽高比反算模型坐标，因此区域会随人物一起移动和放大。用户重新框选确认的`0.4927/0.0482/0.7095/0.1088`已固化为默认及还原值；双点框选仍保留作后续校正，连续滑动触发摸头且10%概率进入大小眼疑惑彩蛋。
- 自主待机开启后以两段错开的`wind_sway_soft`原动作连续循环，彻底替换静止站立，不再使用幅度很小的自制叠加；自然眨眼按Sen实机观感从迷梦约0.20秒放缓为0.34秒。常规动作间隔与最近3次防重复参考迷梦，展示动作保持55%明显风摆/31%视频式环绕/14%展示级大摆、首次28～60秒及后续48～100秒。界面恢复完整26个程序动作按钮，暂不因待机职责自动隐藏任何一项，后续按实机结果逐个删除。
- v0.4.7实机已确认模型原生呆毛根部和物理完全正确；v0.4.8导出进一步确认可用锚点为`ArtMesh151`根顶点`8`与方向三角形`21/5/22`。v0.4.9把该锚点和`56/100/83/-49°`形状固化为Sen默认值，并使用模型局部`X=-0.006`的小幅左移修正实机截图中的右偏；屏幕缩放、拖动和像素坐标均不参与固定参数。重新采集仅保留为可选诊断，失败不会覆盖固化锚点；原生Hair Z、实时标记及呆毛+摸头联合导出继续保留。
- 尾巴固定围绕模型局部中心线镜像到右侧，人物身体和舞台中心保持不变。
- 下方约 1/3 固定测试面板列出 ZIP 表情，预览区保持在上方约 2/3。
- 默认使用原始 2K 贴图；贴图逐张解码上传，不生成 mipmap，并通过主仓库补丁把官方 Framework 的每帧过滤同步改为 `GL_LINEAR`，避免无 mipmap 贴图被采样成纯黑。
- 关闭官方示例的 MOC consistency 重复检查，避免在创建139 MiB moc3时再次复制整份文件。
- 不再使用 WebView、JavaScript、WebAssembly 或联网 Core；渲染和 Core 模型创建都在 Android 原生进程完成。
- 使用 App `largeHeap` 为首次创建超大型模型保留空间，并显示 model3、moc3、表情、物理和每张贴图的原生加载进度。

完整采集快照只作为外观底座与离线对照；服装预设不会复制整份581项快照。DeepSeek对话和TTS口型仍在本轮互动与动态动作实机确认后接入。

## APK 使用

1. 在 GitHub Actions 下载 `Sen-Live2D-Renderer-Test-APK`。
2. 安装 APK，点“导入ZIP”，选择你购买的 `Sen Customizable Model_2K.zip`。
3. 点“导入外观”，选择一次当前采用的 `Sen.vts-profile.json`。以后覆盖安装和切换三套服装不需要再次选择服装JSON。
4. 依次点击“女仆装 / 白衬衫 / 兔女郎”，检查部件、袜子透明度和颜色；白衬衫还应关闭女仆头饰。
5. 需要放大时先点“调整模型：关闭”使其变为开启，再单指拖动、双指缩放；完成后关闭调整避免误触。
6. App 已包含许可允许再分发的官方 `Live2DCubismCore.aar`，不需要联网或单独导入 Core。
7. 首次导入要解压约 139 MiB 的 moc3 和 26 张 2K 贴图，随后由原生 OpenGL 逐步加载，耗时与手机存储速度有关。

从 v0.2.0 起仓库固定使用公开测试签名，后续测试 APK 可以直接覆盖更新。由于 v0.1.x 使用过临时构建签名，首次安装 v0.2.0 若提示签名不一致，需要卸载旧版后安装并重新导入一次模型 ZIP。

## 仓库边界

本仓库和构建产物不包含：

- 用户购买的 Sen 模型、贴图、表情、动作或 VTube Studio 配置；
- VTube Studio 本体或其反编译代码。

仓库以 submodule 固定使用 Live2D 官方 `CubismJavaFramework` 5-r.5，并按官方 `RedistributableFiles.txt` 收录 `Live2DCubismCore.aar`。相关条款见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 与 `Core/LICENSE.md`。

**新对话或新 AI 必须先阅读唯一任务事实源：[docs/SEN_TASK_LEDGER.md](docs/SEN_TASK_LEDGER.md)。** 每轮制作、实机确认、失败结论、踩坑和下一步顺序都维护在其中。
